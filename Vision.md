# Vision

## Why this project exists

Nexus is a long-term project born from a simple goal: to deeply understand how a processor works by designing and building one from scratch.
The first objective is not to create the fastest or the most innovative CPU. The objective is to understand every component, every design choice, and every trade-off involved in a real processor architecture.
This project will evolve through multiple versions. Each version will introduce new concepts while remaining fully understood and documented.

## Long-term vision
In the long term, Nexus aims to become more than a simple CPU.
The project will gradually explore topics such as pipelining, custom instruction set architectures, hardware acceleration, parallel computing, and matrix-oriented computation.
The ultimate goal is to gain enough knowledge and experience to design original computer architectures rather than simply reproducing existing ones.

## Principles
* Understand before optimizing.
* Simplicity over unnecessary complexity.
* Every design choice must have a technical reason.
* Build everything from first principles whenever practical.
* Learn by building, measuring, and improving.
